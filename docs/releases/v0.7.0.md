## AIPic v0.7.0 · 创作工作室与个人模板

本次将 AIPic 更新为统一的中文视觉创作工作室：从模板选用、画面编辑到图片生成与复用，工作流集中在同一界面；同时更新模型参数适配、缓存刷新与多架构部署。

### 新功能

- Kumo UI 工作室重构，统一工作区、模板库、输出设置、历史、AI 助手及明暗主题；整图摄影卡片搭配渐隐毛玻璃文字层。
- 「电商 · 小红书」合并入口，位于 AI Native 前并标记 NEW；包含纯净商品主图、生活场景广告、大字种草封面、清单信息海报和四个完整示例。
- 「我的模板」支持新建、从工作区保存、编辑、删除、封面、生成方式与参数复用；浏览器持久化及同源标签页同步。
- 新手交互教程、清楚的模板到工作区入口、紧凑自适应布局与移动端抽屉。
- 兼容 GPT Image 2.6 系列模型名称与能力，适配扩展质量、复杂度、GIF 帧数/时长和 SVG 参数；贯通 Images、Responses、fal.ai 与 Node 任务后端。

### 修复与体验

- 新 API 配置默认关闭流式传输，保留用户已有选择。
- 修复工作区、文生图、移动端标签的多余阴影与错位底板。
- 修复打开背景及推理强度下拉菜单时的页面跳动。
- 修复 AI 助手输入文字在浅色主题下不可读的问题，统一明暗主题的字色与光标。
- 每次构建生成唯一 build ID；页面检测新构建并刷新，运行任务期间延后；HTML、版本文件与 Service Worker 使用相应缓存策略。
- 保留长请求、任务队列、代理、遮罩、精确尺寸、图片历史与格式兼容能力。

### 本项目贡献与来源

AIPic 负责工作室重构、交互设计、个人模板、中文商业模板适配、模型与任务通路整合、更新机制和发布验证。README 新增按模块说明的贡献表及实现链接。

原始图像前端基础来自 GPT Image Playground（MIT）；后端队列基础来自 FlyReq Image Studio（AGPL-3.0）。商业 skills 的原文、MIT 许可与固定提交均随源码保存；示例提示词为 AIPic 适配。详细归属见仓库 README、backend/README.md、docs/skills-sources.md 和 docs/studio-assets.md。

### 升级说明

- 使用镜像 `ghcr.io/simplaj/aipic:0.7.0`，或下载对应架构的离线包；支持 linux/amd64 与 linux/arm64。
- 在原 Compose 项目目录更新镜像并重建容器，保留 `aipic-data` 数据卷；等待进行中的任务结束后再升级。
- API 配置、页面历史与个人模板仍保存在原浏览器和原站点来源中；切换域名、端口或浏览器不会自动迁移这些数据。
- 模板封面是摄影版式参考；实际图片由用户选择的模型生成，服务商能力以其接口为准。

发布附件包含两种架构的镜像、对应提交源码、Compose 配置、release.json、validation.json 与 SHA256SUMS。校验记录绑定本次提交，UI 回归使用本地响应，不调用付费模型。
